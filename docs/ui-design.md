# UI 设计

> 四大模块的交互设计要点。视觉风格、配色暂未定,本文聚焦于**交互结构**和
> **可视化方案选择**。

---

## 整体导航

底部 Tab(4 个):
1. **时间线** — 默认页
2. **朝代图** — 朝代脉络可视化
3. **人物** — 人物列表 + 搜索 + 收藏
4. **做题** — SRS 队列 + 自由练习

顶部右上角:**设置**(LLM 配置、模式切换、关于)

任意视图都能"跳转视角":
- 时间线点事件 → 弹关联人物
- 人物卡 → "参与的事件"跳时间线
- 朝代图 → 点朝代 → 该朝代时间线 / 人物列表
- 这种"任意切换视角"是产品核心价值

## 模块 1: 时间线

### 滚动方向: 纵向

横向时间线在手机上不好(横屏才舒服)。**纵向滚动 + 朋友圈式 feed**,符合手
机交互肌肉记忆。

### 缩放尺度(核心交互)

类似 iOS 相册按年/月/日缩放,这是核心体验。pinch-to-zoom 切换层级:

| 层级 | 显示内容 |
|---|---|
| **通史**(全图) | 朝代色带 + 大转折点(秦统一、汉武、安史之乱、鸦片战争等 ~10 个) |
| **朝代级** | 该朝代色带 + 主要事件 ~30 个 |
| **世纪级** | 全部事件,密集显示 |
| **十年级** | 单个十年内全部事件 + 月日精度 |

### 颜色编码

`event.category` 用颜色区分:
- 战争 — 暗红
- 政治 — 深蓝
- 文化 — 橙
- 科技 — 青
- 外交 — 紫
- 经济 — 绿
- 人物 — 灰

### 传说时代渲染

`historicity: legendary` 的事件 / 人物 → **雾化 / 半透明 + 虚线时间轴**,
区别于实证历史,UI 上不做硬"边界",自然过渡。

### 筛选

顶部筛选条:
- 朝代多选
- 类别多选
- 关键词搜索(联动事件名 + 人物名)

## 模块 2: 朝代脉络图(最难也最核心)

### 决策:多车道 Swimlane,不是单线

教科书封底的"夏→商→周→秦→汉→…"单线图丢失了所有有趣的部分(三国、南北朝、
五代十国并立)。

```
时间 ↓                                           车道
                                    ┌─ 主车道 ─┬─ 北方 ─┬─ 南方 ─┬─ ...
公元前 1046  周                       周         │       │       │
公元前 770   春秋(列国)              ╱╲╱╲╱╲     │       │       │
公元前 475   战国(七雄)              ╳╳╳╳╳╳     │       │       │
公元前 221   秦                       秦         │       │       │
公元前 202   汉                       西汉       │       │       │
公元 8       新                       新         │       │       │
公元 25      东汉                     东汉       │       │       │
公元 220     三国                     ⮕分叉     魏      │       蜀/吴
公元 280     西晋(短暂统一)          晋         │       │       │
公元 304     十六国/东晋              ⮕分叉     北方诸国 │       东晋
公元 420     南北朝                   ⮕         北朝     │       南朝
公元 589     隋                       隋(汇合)
...
```

### 实现技术

Flutter `CustomPainter` 自绘:
- 数据驱动:输入 dynasties + regimes,输出绘制
- 不要用现成图表库(`fl_chart`、`syncfusion` 都不合适)
- 可缩放(平滑放大某个时段查看细节)
- 可点击(点车道色块 → 进入该朝代/政权详情)

### 视觉提示

- 主车道色彩饱满,分支车道略淡
- 分裂期车道明显分叉(动画)
- 汇合期合流(如"隋统一")
- 短命王朝(秦/新/隋)特殊标注

## 模块 3: 人物卡 + 做题

### 卡片设计

**正面**(列表预览):
- 朝代色带(顶部)
- 人物头像占位 / 朝代代表性纹样(自用阶段不用真画像,版权省心)
- 姓名 + 一句话标签("北宋政治家、变法领袖")

**背面 / 详情**(点击展开):
- 完整 summary
- 生平时间线缩略版(关联 events)
- **关系网图**(以该人为中心放射,师生 / 父子 / 朋友 / 对手)
- 代表作品列表
- "和他对话"按钮 ⭐(进入 chat 模块)

### 关系网图

在人物详情页用力导向图(force-directed graph)展示该人物的关系网络。Flutter
有 `graphite` / `flutter_force_directed_graph` 等包可用,或者用
`CustomPainter` 自绘小型(~10-20 节点)的版本。

点节点 → 跳到那个人物的详情。

### 做题(SRS 间隔重复)

**这是真正能学到东西的关键**,不要做成"刷一遍就完"。

#### 题型

| 题型 | 例 |
|---|---|
| 单选 | "新法变法领袖是?" → 王安石 / 司马光 / 苏轼 / 范仲淹 |
| 多选 | "北宋四大书法家?" |
| 时间排序 | 拖拽排列 4 个事件 |
| 连连看 | 人物 ↔ 朝代 / 著作 / 事件 |
| 看像识人 | (自用阶段先不放真图,用纹样) |
| 填空 | "______ 是北宋政治家、变法领袖" |

#### SRS 调度

借鉴 Anki SuperMemo-2 算法的简化版:

```dart
class SrsCard {
  DateTime nextReview;
  double interval;     // 天数
  double easiness;     // 记忆强度 (1.3 - 2.5)
  int repetitions;
}
```

答错 → repetitions = 0, interval = 1 天
答对 → repetitions++, interval = interval * easiness, 下次复习时间推后
答太对(秒答) → easiness 上调

每天首页推送"今日待复习"列表。

## 模块 4: 对话(chat)— 核心特色

### 入口

任何看到人物的地方都有"💬 与他/她对话"按钮:
- 人物详情页底部
- 时间线点击事件 → 弹出参与人物 → 直接对话
- 朝代图 → 朝代代表人物快捷入口

### 会话列表

每个 person 可以有多条 session(类似 ChatGPT 的多对话):
- 默认开新 session
- 可以回到旧 session 继续聊
- session 之间独立(不共享上下文)

### 消息 UI

- 用户气泡:右侧,主色调
- 人物气泡:左侧,带朝代色带 + 名字标签
- **流式输出**(必须):字逐字出现
- 长回复可"展开/收起"
- 长按消息:复制 / 重新生成 / 收藏(收藏后可作为做题素材源)

### 模式切换

会话顶部有 toggle:**严肃模式 / 演义模式**
- 切换会清空当前 session(因为人设不同,前后矛盾)
- 提示:"切换模式将开始新对话,旧对话保留在历史"

### 设置入口(进入对话前提示)

如果用户没填 LLM key:
- 第一次点击对话按钮 → 引导填 baseUrl / apiKey / modelName
- 提供"使用示例配置"按钮(指向 DeepSeek 注册页)

## 视觉风格(草案,后续 OpenSpec 提案细化)

- **整体**: 简洁现代 + 中国传统配色点缀
- **朝代色板**: 每个朝代一个代表色(夏黄、商青铜、周朱红、秦黑、汉绛、唐金、
  宋青、元蒙白、明红、清黄)— 用于色带、卡片标识
- **字体**: 系统默认 + 标题用稍古风衬线(如思源宋体)
- **暗色模式**: 必须支持(看历史多在睡前)
- **动画**: 克制,只在转场和缩放时用,不做过度动效
- **响应式**: 平板视图考虑(后续),v1 主攻手机竖屏
