# 时间线模块设计

> Phase 1 主战场。本文档是时间线模块的当前事实来源。
> 创建于 2026-05 重定位 — 时间线从"4 大模块之一"升级为"Phase 1 起点"。

## 角色定位

时间线是这个 app 的**主入口和门面**。打开 app 第一眼看到的就是它。
其他模块(朝代图 / 人物卡 / 做题)都是从时间线**点击进入**的支线。

```
                  app 启动 → 默认进时间线
   ════════════════════════════════════════════════════

         ┌──────────────────────┐
         │   时间线 (主入口)     │  ← 用户大部分时间停在这里
         └──────────┬───────────┘
                    │
       ┌────────────┼────────────┬────────────┐
       ▼            ▼            ▼            ▼
   ┌───────┐    ┌───────┐    ┌───────┐    ┌───────┐
   │ 朝代图 │    │ 人物卡 │    │ 做题  │    │ 设置  │
   └───────┘    └───────┘    └───────┘    └───────┘
   (从朝代色块)  (从事件参与者) (单独入口)
```

## Phase 1 范围(最小可用)

**时段**: 先秦 + 春秋战国(到秦统一止)
- 起始: 约 -2070(传说夏朝)
- 结束: -221(秦统一)
- 跨度: ~1850 年

**事件量**: 30-50 条
- 传说时代: 5-10 条(三皇五帝、夏、商、周)
- 西周: 5-10 条
- 春秋: 8-12 条
- 战国: 10-15 条
- 秦统一前夕: 3-5 条

**功能**:
- ✅ 纵向滚动(由旧到新,从上到下)
- ✅ 朝代色块背景(西周 / 东周春秋 / 战国 / 等)
- ✅ 事件卡片(年份 + 名称 + 1-2 行简介)
- ❌ 缩放(Phase 1 不做,Phase 2 加)
- ❌ 横向滚动(永远不做,纵向是基本盘)
- ❌ 事件详情页(Phase 1 卡片就是终点,Phase 2 加详情)
- ❌ 事件分类配色(Phase 2)
- ❌ 关联人物跳转(Phase 2)

## 数据契约

时间线只读 `events.json` 和 `dynasties.json`。

**event 必填字段**(Phase 1 子集):

```json
{
  "id": "event_zhouwang_fa_zhou",
  "name": "武王伐纣",
  "year": -1046,
  "yearUncertainty": "decade",
  "dynastyId": "dynasty_western_zhou",
  "summary": "周武王率诸侯联军于牧野击败商纣王,商朝灭亡,西周建立。",
  "category": "politics"
}
```

字段含义见 `docs/data-schema.md`(草案)。Phase 1 不要求 `participants /
locationName / outcome / relatedEvents` 等字段。

**dynasty 必填字段**(Phase 1 子集):

```json
{
  "id": "dynasty_western_zhou",
  "name": "西周",
  "startYear": -1046,
  "endYear": -771,
  "color": "#A0826D"
}
```

`color` 用于时间线背景色块。建议用相邻朝代色调差异明显的配色,见 `docs/ui-design.md`。

## 排序与不确定性

事件按 `year` 升序排列。Phase 1 不处理同年多事件的次序问题(无所谓)。

**不确定年份**:
- `yearUncertainty: "decade"` → UI 显示"约 -2070 年代"
- `yearUncertainty: "century"` → UI 显示"约公元前 21 世纪"
- `historicity: "legendary"` 的事件(传说时代)用斜体 + 浅色

## 性能预算

Phase 1 事件量 30-50 条,**纯 ListView 无虚拟化也跑得动**。Phase 2-3 会扩到
几百条,届时再考虑 `ListView.builder` + 索引。

启动加载: `rootBundle.loadString('assets/data/events.json')` 一次性读全部,
JSON 解析进内存,**< 50ms**(50 条 × 300 字节 ~= 15KB)。
